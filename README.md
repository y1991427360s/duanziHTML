# 端子排出图工具

本项目只保留最终简洁版。

## 使用方法

1. 双击 `出图工具.cmd`。
2. 在浏览器页面粘贴端子排坐标或普通端子清单。
3. 接线资料可填写，也可留空只画端子排。
4. 点击“生成图纸”，DXF 自动保存到桌面。

坐标格式为：

```text
20453.52,-4715.01 1QD
20453.52,-4720.01 1
```

程序按横坐标分组：横坐标相同的全部内容属于同一块物理端子排。该列中出现的多个名称段会按纵坐标顺序连续放在同一条横向端子排里。纯数字作为端子号，`A610`、`+KM1`、`1(2)B-A4111` 等原理号自动忽略。

## 固定出图规则

- 每一种横坐标生成一条横向端子排；同一横坐标内可以包含多个不同名称的连续端子段。
- 端子格节距为 5 mm，端子排总高为 75 mm。
- 每块物理端子排的电缆方向可单独选向上或向下：端子排输入框下方会自动列出每一块并配一个方向按钮，默认向下，各块互不影响。
- 每行电缆距离独立从 10 mm 开始，再按 15、20、25……递增。
- 同一端子接多根电缆时，引线按 1 mm 间距在端子中心两侧平均分配；左侧引线对应离端子排更近的电缆。
- 文字样式为 `HZ`，字高 3，宽度因子 0.7，色号 7。
- 图纸由可编辑的 `LINE` 和 `TEXT` 实体组成。

## 文件

- `出图工具.cmd`：双击启动入口。
- `duanzi_dxf_tool.py`：页面、解析和 DXF 生成程序。
- `test_duanzi_dxf_tool.py`：重复端子引线分配及 DXF 回读测试。
- `html电缆/`：CAD 原始图纸和清册，不属于运行依赖，但作为源资料保留。
