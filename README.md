# 端子排出图工具

把端子排清单和接线清单粘进窗口，直接生成符合出图规则的 DXF。只保留桌面 GUI 版（tkinter 窗口），没有浏览器页面和本地服务。

## 启动

- 日常使用：双击 `端子排出图工具.lnk`，它指向打包好的 `dist\端子排出图工具.exe`，不需要装 Python。
- 从源码运行：双击 `端子排出图桌面版.cmd`（旧的 `出图工具.cmd` 指向同一个界面），或执行 `python duanzi_gui.py`。需要先 `pip install ezdxf`。

## 使用步骤

1. 在「① 端子排」框粘贴端子排：普通格式一行一块，例如 `ZD、1、11`；坐标格式每行 `横坐标,纵坐标 文字`，名称行以 `端子名` 结尾。
2. 在「② 接线」框粘贴接线：一行一条 `端子号、原理号、去向柜`，同一根电缆只在最后一条写去向柜；也可以留空，只画端子排。
3. 右侧方向表会随输入自动列出每块端子排。单击「方向」格可以切换向上/向下；也可以多选后点「选中向上」「选中向下」。改「默认方向」会把全部块设成同一方向。
4. 按 `Ctrl+Enter` 或点「生成 DXF」。默认保存到桌面，也可以在「输出目录」里换位置，目录不存在时会询问是否新建。

窗口用法：

| 操作 | 说明 |
| --- | --- |
| `F5` / 检查输入 | 列出识别到的端子排，校验接线，只报问题不出图 |
| `Ctrl+Enter` / 生成 DXF | 生成完整图和仅接线图 |
| 导入文本… | 直接读 txt/csv，自动识别 UTF-8、GBK 和 UTF-16 |
| 右键 | 剪切、复制、粘贴、撤销、全选；结果区也能右键复制 |
| 行号 | 报错里的「第 N 行」对照输入框左侧行号 |
| 生成后自动打开完整图 | 勾选后生成完直接用关联的 CAD 打开 |
| 打开文件夹 | 在资源管理器里选中刚生成的图 |

输入内容、柜名、方向和输出目录会在生成成功和关窗时保存到 `%APPDATA%\端子排出图工具\state.json`，下次打开自动恢复。「填入示例」和「清空」会先确认，输入框内容可以按 `Ctrl+Z` 撤销。

每次生成两份 DXF：完整图会锁定端子排框线、名称、编号和图签图层；原理号放在单独的未锁定图层，引线、电缆线、三角和电缆文字都可以编辑。仅接线图（文件名以 `-仅接线.dxf` 结尾）只含这些接线对象，坐标和完整图一致，可以直接全选复制。同名图正开在 CAD 里写不进去时，会自动改用带日期时间的文件名。

DXF 锁层不能保证所有 CAD 都禁止选中或复制锁定对象。需要复制时完全不带端子排，请用仅接线图；完整图里的端子排仍然可见，并受锁层保护。

## 输入规则

两种输入格式不能在同一段里混用。混用时会报出是第几行不符合，不会生成图纸。

坐标格式示例：

```text
-2435.48,992.73 X 端子名
-2297.36,992.73 X2 端子名
-2435.48,987.73 1
-2297.36,987.73 51
```

- 程序按横坐标分组，横坐标相同的内容属于同一块物理端子排；同一列里的多个名称段按纵坐标顺序连成一条横向端子排。
- 端子排名称必须写成 `X 端子名`、`X2 端子名` 这种格式，只认行末的「端子名」标记，不按名称形态猜测。
- 没有标「端子名」的每行文字都按端子号保留，数字、汉字或混合文字都可以。
- 同一块里端子号重复时，每格都会画在自己的位置，接线接到第一次出现的那一格，并给出提醒。
- 没有名称可以归属的文字会报错，而不是悄悄丢掉：竖排时是没有名称的列或名称上方的文字，横排时是没有名称的整排或第一个名称左边的文字。
- 坐标之间必须用逗号，坐标和文字之间用空格。用制表符分隔的坐标不会被认成坐标格式，会报「端子排名称是纯数字」。

普通格式：一行一块，第一项是名称。以 `D` 结尾的名称、`QD-COM`、以及 `X`、`X2` 这类短名称，出现在行中间时会自动另起一块；同名的几段会接成一块。纯数字的名称会直接报错。

接线端子引用：

- 半角冒号、全角冒号、连字符和空格不影响匹配，`ZD2`、`ZD:2`、`ZD：2` 等价。
- `QD-COM` 是有效的端子排名称，`QD:COM1`、`QD：COM1`、`QD-COM1` 都表示 `QD-COM` 的 1 号端子，1 至 8 号同理。
- 写了冒号就按冒号拆：`X2:1` 只能是 X2 的 1 号，X2 没有这个端子时会报错，不会改接到 X 的 21 号。
- 不写冒号又有几种拆法时（例如 `X21` 既可能是 X2 的 1 号，也可能是 X 的 21 号），按名称最长的拆，并提醒改用冒号写明。
- 只有真实存在的端子才会触发连续接线的自动分段，`JD-901` 这类原理号不会被拆成端子。

## 固定出图规则

- 每一种横坐标生成一条横向端子排；同一横坐标内可以包含多个不同名称的连续端子段。
- 端子格节距为 5 mm，端子排总高为 75 mm。
- 每块物理端子排的电缆方向可以单独选向上或向下，默认向下，各块互不影响。
- 每行电缆距离独立从 10 mm 开始，按 15、20、25……递增。
- 同一端子接多根电缆时，引线以 1 mm 间距在端子中心两侧平均分配；左侧引线对应离端子排更近的电缆。
- 向上电缆的竖直引线在最上端带 `SJ` 上接短线，向下电缆在最下端带 `XJ` 下接短线。
- 端子排内的原理号为 ACI 4 青色，水平电缆直线为 ACI 3 绿色；其余对象保持 ACI 7。
- 文字样式为 `HZ`，字高 3，宽度因子 0.7，色号 7。
- 电缆标注采用 `AA整合版本.lsp` 中 `BIAN` 命令的基准：电缆线右端左侧 40 mm 为方向三角尖点，编号在尖点左 20 mm，`至` 在右 1.5 mm，规格在右 32 mm。
- 图纸由可编辑的 `LINE` 和 `TEXT` 实体组成。

## 文件

- `端子排出图工具.lnk`：日常启动入口，指向 `dist\端子排出图工具.exe`（本机路径，不入库）。
- `端子排出图桌面版.cmd`：从源码启动的入口。
- `出图工具.cmd`：旧入口，指向同一个界面，保留是为了旧快捷方式还能用。
- `duanzi_gui.py`：tkinter 界面，负责输入、方向表、状态保存和调用出图。
- `duanzi_dxf_tool.py`：解析和 DXF 生成模块，不含界面。
- `test_duanzi_dxf_tool.py`：输入解析、接线引用、重复端子引线分配和 DXF 回读测试。
- `test_duanzi_gui.py`：界面逻辑测试（隐藏窗口运行，不碰真实的状态文件）。
- `端子排出图工具.spec`：PyInstaller 打包配置，产物在 `build/`、`dist/`（都不入库）。
- `图标.ico`、`图标.png`：程序图标，`图标.ico` 会打进 exe。
- `html电缆/`：CAD 原图和清册，不是运行依赖，作为源资料保留。

## 验证与打包

```text
python -m py_compile duanzi_dxf_tool.py duanzi_gui.py
python -m unittest -v test_duanzi_dxf_tool.py test_duanzi_gui.py
python -m PyInstaller --noconfirm 端子排出图工具.spec
```

改了 `duanzi_gui.py` 或 `duanzi_dxf_tool.py` 之后必须重新打包，否则双击快捷方式用的还是旧 exe。
