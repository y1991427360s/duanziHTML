# 端子排接线规划器 V1.0

面向电气二次设计的本地工具：填端子排和接线，直接输出可以用 CAD 打开的 DXF 图纸。

有两个入口，按需要挑一个：

| 入口 | 适合 | 怎么用 |
| --- | --- | --- |
| **简易版**（推荐日常用） | 只想出图，不想学界面 | 双击 `出图工具.cmd` → 浏览器自动打开 → 填两个框 → 点「生成图纸」→ 桌面上出现 DXF |
| 完整版 | 要逐条编辑、看预览、调绘图参数、导出脚本 | 双击 `index.html` |

两个入口的输入格式、排线规则和出图参数完全一致。

## 简易版：填两个框就出图

双击 `出图工具.cmd`（或运行 `python duanzi_dxf_tool.py`）。会弹出一个黑色命令行窗口，浏览器随即打开一个只有三步的页面：

1. **有哪些端子排** —— 一块端子排写一行：先写名称，后面挨着写端子号。

   ```
   ZD、1、11
   1-2ID、1、2、3、4
   JD、1、4
   ```

2. **怎么接线** —— 一条接线写一行：端子号、原理号。一根电缆的**最后一条**再加上**去向柜**；前面没写去向柜的自动算成同一根电缆。

   ```
   ZD1、+KM1
   ZD11、-KM1、直流馈线柜
   1-2ID4、1(2)B-N4121
   1-2ID1、1(2)B-A4121、35kV 1(2)#主变进线柜
   ```

3. **出图** —— 填个柜名（可留空），点「生成图纸」。

**整段用顿号连成一行也认**，不用先手动分行。端子清单里遇到像端子排名称的项（含字母、以 `D` 结尾，例如 `1-2ID`）就自动开下一块；接线里遇到「端子排名称+端子号」的项（例如 `ZD11`）就自动断成新的一条。所以下面这一整行和上面分行写的结果完全一样：

```
ZD、1、11、1-2ID、1、2、3、4、JD、1、4
ZD1、+KM1、ZD11、-KM1、直流馈线柜、1-2ID4、1(2)B-N4121、1-2ID1、1(2)B-A4121、35kV 1(2)#主变进线柜
```

只有端子排名称不以 `D` 结尾（或端子号恰好以 `D` 结尾）时，整段连写才认不出来，这时按一块一行写。

页面会给出图纸路径、一个「用 CAD 打开」按钮、识别到的端子排清单（`ZD（2 个端子） ｜ 1-2ID（4 个端子） …`），以及每根电缆的归属（`WL-01 → 直流馈线柜：ZD-1 ZD-11`），可以不开 CAD 就核对一遍。输入有问题时按条列出来，例如“第 2 条「ZD99、B、某柜」：ZD 没有 99 号端子”，同时也把识别到的端子排一起显示，方便看出是不是断句断错了；错误多于 10 条时只列前 10 条。

图纸存到桌面，文件名 `<柜名>-端子排接线图.dxf`；同名文件会被覆盖，如果上一份正被 CAD 占用则自动加时间戳。电缆号自动编成 `WL-01`、`WL-02`……，规格留空（图上写“未填写”），后续在 CAD 里补。

页面里的“填入示例看看”会一次填好上面三项，照着改最快。用完关掉那个黑色命令行窗口即可。

依赖：Python + `ezdxf`（缺少时执行 `pip install ezdxf`）。

## 完整版：index.html

直接双击 `index.html`，纯前端，不需要服务器。除了简易版的能力，还可以：可视化预览并缩放、逐条编辑接线、切换向上/向下接线、调首层间距和文字高度、按端子排分别出图、保存/打开 JSON 项目、导出 SVG，以及导出「出图脚本」——一个把参数区和固定绘图代码放在一起的 Python 文件，之后改参数区重跑即可重出图。

1. 在“端子排”页新增、删除、重命名端子排，并编辑端子号及顺序。
2. 在“接线”页新增或编辑接线点。每条记录包含端子、原理号、电缆号、起点柜、去向和规格。
3. 在“参数”页切换向上/向下接线，调整首层间距、层间距和文字高度，这些参数会一起写进出图脚本。
4. 在预览中点击线路或标签查看整根电缆的接线点、去向和规格。
5. 鼠标滚轮缩放，按住鼠标左键拖动平移，双击恢复，或使用顶部视图按钮。缩放百分比以 1 个绘图单位 = 1 像素为 100%，点击中间的百分比按钮回到 100%，“适应窗口”把整张图放进画布。
6. 顶栏“生成出图脚本”导出当前端子排（或组合）的 Python 出图脚本；“保存 JSON”保存全部项目数据；“导出 SVG”只用于快速看图和贴文档，不是出图用的成品。

端子排名称对不上任何一块端子排的接线，会集中显示在“接线”页顶部的“未归属的接线”区，可以直接改端子排名称或删除；端子号不存在的接线留在所在端子排的列表里，下拉框中标注“（不存在）”。

## 引导工作流（完整版）

在 `index.html` 里点击顶部“开始工作流”，按照四步向导操作。简易版把这四步压成了一页，规则相同，只是不分 `layoutGroup`（一次粘贴的所有端子排画在一张图上）。

### 第一步：端子清单

一块端子排一行，第一项是端子排名称，后面全部是端子号：

```
1ZD、1、2、3、4、5、6、7
2ZD、1、2、3、N、PE

JD、1、2、3、4
```

- 行内用逗号、顿号或 Tab 分项；换行或分号开始下一块端子排。
- 端子号按原样保留，`N`、`PE`、`1A` 这类带字母的端子号可以直接写。
- 整段用顿号连成一行也认：中途遇到像端子排名称的项（含字母、以 `D` 结尾）会自动开下一块。
- 空行分隔物理组合：同一段里的多块端子排会写入同一个 `layoutGroup` 并连续绘制，单独一段的端子排保持独立显示。

### 第二步：核对端子

确认拆分出的端子排名称、端子数量和端子顺序。这一步可以选择“仅导入端子排，稍后接线”，只把空模板放进编辑器。

### 第三步：接线资料

一条记录写“端子号、原理号”，这根电缆的最后一条记录再补上“去向柜”：

```
ZD1、+KM1；
ZD11、-KM1、直流馈线柜；
1-2ID4、1(2)B-N4121；
1-2ID1、1(2)B-A4121；
1-2ID2、1(2)B-B4121；
1-2ID3、1(2)B-C4121、35kV 1(2)#主变进线柜
```

- 记录之间用分号或换行分隔，记录内部用逗号、顿号或 Tab 分项。空的原理号不会打乱后面的字段。
- 整段用顿号连成一行也认：遇到「端子排名称+端子号」的项（例如 `ZD11`）会自动断成新的一条。
- 没有写去向柜的记录，自动和它后面第一条写了去向柜的记录归成同一根电缆；上例是 2 根电缆，分别 2 个和 4 个接线点。
- `1-2ID4` 会按已有端子排名称拆成端子排 `1-2ID` 和端子号 `4`；同时存在 `1D` 和 `1D1` 这类前缀重叠的名称时，工具会依次尝试并采用端子真实存在的那一种。
- 电缆号按“电缆号前缀 + 两位序号”自动生成（默认 `WL-01`、`WL-02`……），追加导入时自动跳过已占用的编号；起点柜在导入框里统一填写。
- 规格不在这一步录入，应用后每根电缆会有一条“缺少规格”的警告，在“接线”页补填即可。

### 第四步：生成出图脚本

显示端子排、端子、接线点和电缆数量，点“生成 DXF 出图脚本”下载 `<项目名>-<视图名>-出图.py`；想先看预览就点“先看接线预览”，回主界面后顶栏的“生成出图脚本”按钮效果相同。

工作流草稿（两个文本框的内容、起点柜、电缆号前缀、导入方式）会保存在当前浏览器本地存储中。全部解析都是确定性的文字拆分，不使用图片识别，也不需要 AI 返回 JSON。

## 出图：Python 脚本 → DXF

“生成出图脚本”导出的 `.py` 分成两段：

```python
# ==================== 参数区：随每次输入变化 ====================
PARAMS = {
  "projectName": "35kV 1#主变保护柜",
  "viewName": "组合端子排-1",
  "direction": "DOWN", "firstDistance": 10, "distanceStep": 5, "textHeight": 3,
  "terminalBlocks": [{"name": "ZD", "terminals": ["1", "11"]}],
  "connections": [{"terminalBlock": "ZD", "terminal": "1", "principle": "+KM1", ...}]
}
# ==================== 以下为固定代码，一般不需要改 ====================
```

参数区就是这次输入的结果，下面的绘图代码每次都一样。改端子、改原理号、改去向、改文字高度，直接编辑参数区重新运行即可，不必回到网页。

运行方式：

```powershell
python "35kV 1#主变保护柜-组合端子排-1-出图.py"          # 在脚本同目录生成同名 .dxf
python "...-出图.py" D:\图纸\端子排.dxf                    # 指定输出路径
python "...-出图.py" --open                                # 生成后直接打开
```

脚本会打印图形范围、统计数量，并自动回读 DXF 校验文字样式、实体数量和每个 `TEXT` 的宽度因子；端子不存在或缺电缆号的记录会以“提示”列出并跳过，不会静默丢失。

出图约定（沿用 ys199 的常用 CAD 参数，都写在脚本的 `DRAWING` 里）：

| 项目 | 取值 |
| --- | --- |
| 图形单位 | 1 单位 = 1mm，`$INSUNITS = 4` |
| DXF 版本 | R2010 |
| 文字样式 | `HZ`（`txt.shx` + `hztxt.shx`），宽度因子 `0.7` 同时写入样式和每个 `TEXT` |
| 颜色 | 色号 `7`，随背景黑白，白底打印可见 |
| 端子格宽 / 端子号栏高 | 固定 `5` / `5`，端子排名称格宽 `10` |
| 图层 | `端子排-框线`、`端子排-文字`、`电缆-接线`、`电缆-文字`、`图签-文字` |
| 实体 | 表格线和接线用 `LINE`，全部文字用 `TEXT`，不含图片和块 |

端子排内的文字（端子排名称、端子号、原理号）旋转 90°，其文字高度就是横向占位，超过端子格宽时脚本会自动收敛到 `3.5` 并打印提示。中文依赖 CAD 里的 `hztxt.shx`；若你的 CAD 没装这个大字体，把 `DRAWING["bigfont"]` 改成实际可用的中文大字体即可。

一次导出一个端子排（或一个 `layoutGroup` 组合），和预览画布保持一致。多块端子排分别切换后各导一份脚本。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `出图工具.cmd` | 简易版启动器，双击即用。内容必须保持**纯 ASCII + CRLF 换行**：cmd.exe 按系统代码页读批处理，写中文或用 LF 换行都会让它把命令行拆错（会报 `'5001' 不是内部或外部命令`）。文件名本身可以是中文。 |
| `duanzi_dxf_tool.py` | 简易版本体：简单页面 + 输入解析 + DXF 生成（本地 127.0.0.1 小服务，只监听本机）。用英文名就是为了让启动器保持纯 ASCII。 |
| `index.html` | 完整版界面与四步工作流 |
| `app.js` | 数据管理、校验、SVG 预览、Python 脚本导出 |
| `python-template.js` | 完整版导出的出图脚本模板，导出时只替换参数区 |
| `style.css` | 完整版样式 |
| `*.json` | 示例项目 |

`.gitattributes` 已用 `*.cmd text eol=crlf` 固定批处理换行，避免仓库统一 LF 后再次把启动器改坏。

绘图代码在 `duanzi_dxf_tool.py` 和 `python-template.js` 里各存一份（一份给简易版直接用，一份是完整版导出的独立脚本），改绘图逻辑时两处都要改。

## JSON 数据格式

```json
{
  "projectName": "项目名称",
  "terminalBlocks": [
    {"name": "ZD", "terminals": [{"number": "1"}, {"number": "2"}]}
  ],
  "connections": [
    {
      "terminalBlock": "ZD",
      "terminal": "1",
      "principle": "+KM1",
      "fromCabinet": "公用测控及时钟同步系统柜",
      "toCabinet": "直流馈线柜",
      "cableNumber": "ZL-01",
      "cableSpec": "2×4"
    }
  ],
  "settings": {"direction": "DOWN", "firstDistance": 10, "distanceStep": 5, "textHeight": 3}
}
```

`cableNumber` 是同一根电缆的唯一分组标识。端子始终按 `terminalBlocks[].terminals` 中的顺序显示，与 connections 的记录顺序无关。V1 不包含厂家原理号字段。

## 排线层级规则

电缆首先按各自全部接线点中“最靠左端子”的位置排序：最左接线端子越靠左，电缆越靠近端子排，从而形成由左上向右下递增的阶梯。两根电缆的最左端子位置相同时，再按电缆号自然排序，避免 `DS-10` 排在 `DS-2` 前面。

## 组合端子排

厂家图片中物理连接在一起的多个端子排，使用相同的 `layoutGroup`：

```json
{
  "name": "17D",
  "layoutGroup": "厂家组合端子排-1",
  "terminals": [{ "number": "1" }, { "number": "2" }]
}
```

相同 `layoutGroup` 的端子排会按 `terminalBlocks` 数组中的顺序连续绘制。点击其中任意一个成员，预览都会显示整个组合，电缆层级也会跨整个组合按最左接线端子统一排序。`layoutGroup` 留空时保持独立预览。

端子排预览采用连续表格形式：端子排名称、端子号和用户填写的原理号均逆时针旋转 90°。端子号栏高度固定为 5，默认文字高度为 3。向下接线时原理号位于端子号栏下方，向上接线时自动镜像到上方；引线从每个端子列的水平中心向所选方向引出。

`firstDistance` 和 `distanceStep` 仅控制 SVG 中首层间距和后续层间距，不进行线路长度计算。层间距会自动保证不小于电缆标签高度，避免相邻电缆信息重叠。

`DOWN` 表示线路从端子向下展开，`UP` 表示向上展开。`textHeight` 是 CAD 参数，界面会映射为可读的 SVG 字号，不直接当作像素值。

## 数据检查

- 错误：端子排不存在、端子不存在、端子号重复、缺少电缆号。
- 警告：同一端子存在多个接线关系、整根电缆缺少去向、整根电缆缺少规格。缺少去向和缺少规格按电缆汇总，不会每个接线点重复提示。

不存在的端子不会绘制，重复关系保留并交给用户处理。数据检查面板显示当前端子排的问题，外加所有端子排名称对不上的问题。

## 当前限制

- 一个预览画布、一份出图脚本一次处理一个端子排（或一个组合）。
- 不读取或修改 DWG，也不调用 CAD API：出图路径是 Python + ezdxf 生成 DXF，再用 CAD 打开或插入既有图纸。
- 不含 OCR 和 AI 识别，端子清单与接线资料都靠确定性的文字拆分。
- 浏览器出于安全限制不能覆盖原 JSON 文件，保存操作会下载新文件。
- 没有撤销功能，删除端子和删除接线点没有二次确认，误删后请重新导入 JSON。

数据管理、校验、SVG 预览和出图脚本生成在代码中保持独立，后续可以增加 DWG 数据导入器或其他输出器而不改动核心项目模型。
