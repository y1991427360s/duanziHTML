第一步

一块端子排一行：先写名称，再写端子号

每一行（或每个分号）就是一块端子排：第一项是端子排名称，后面全部当成端子号，N、PE、1A 这类带字母的端子号也可以直接写。整段用顿号连成一行也认，遇到下一个端子排名称会自动断开。物理上连在一起的几块端子排写在同一段里，中间空一行就换成下一个组合。

同一段里的多块端子排会按顺序连续绘制；单独一段的端子排独立显示。
第二步

核对自动拆分出的端子排

确认端子排名称、数量和端子顺序。同一段里的多块端子排会标为连续组合，单独一段的端子排显示为独立。

第三步

粘贴接线资料

一条记录写端子号、原理号；这根电缆的最后一条记录再补上去向柜。没有写去向柜的记录，自动和它后面第一条写了去向柜的记录归成同一根电缆。记录之间用分号或换行分隔，整段用顿号连成一行也认，遇到下一个端子号会自动断成新的一条。

第四步

接线已经排好，可以出图了

点“生成 DXF 出图脚本”会下载一个 Python 脚本，双击或 python 脚本名.py 运行即在同目录生成 DXF，直接用 CAD 打开。脚本里只有顶部参数区随本次输入变化，改完参数重新运行即可重出图。

下一步建议 先在预览中检查每根电缆的阶梯顺序，再处理数据检查中的警告。
